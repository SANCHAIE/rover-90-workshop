# Rover 90

**คู่มือพาทำเวิร์กช็อปหุ่นยนต์ ESP32 · 90 นาที · นักเรียน ม.ปลาย 15 ทีม**

หน้านี้เรียงตามลำดับเวลาจริง อ่านไล่จากบนลงล่างแล้วทำตามได้เลย
ตั้งแต่สัปดาห์ก่อนงานจนถึงเก็บของหลังจบคาบ

นักเรียนจะได้ **ต่อวงจรเองทั้งคัน · เขียนโค้ดให้รถวิ่ง · ปรับจูนจนวิ่งได้ระยะแม่น · เปิดหน้าเว็บของรถบนมือถือตัวเอง**

# ระยะที่ 1 · สัปดาห์ก่อนงาน

## 1.1 ซื้อของส่วนกลาง

อุปกรณ์ในชุดนักเรียนมีครบแล้ว แต่ **ของส่วนกลางยังต้องหาเอง** ดูรายการเต็มในชีตที่สองของ [`bom/BOM.xlsx`](bom/BOM.xlsx)

สองรายการนี้ถ้าไม่มี กิจกรรมเดินไม่ได้จริง ๆ

- [ ] **เครื่องชาร์จ 18650 แบบ 4 ช่อง 2 เครื่อง** — ถ่าน 30 ก้อนมาแบบไม่ได้ชาร์จ
- [ ] **ตลับเมตรหรือไม้บรรทัดเหล็ก ทีมละ 1 อัน** — ช่วงปรับจูนคือการวัดล้วน ๆ

ที่เหลือควรมี

- [ ] ถ่าน 18650 สำรอง 4 คู่ · มัลติมิเตอร์ 2 เครื่อง · สายต่อ USB 5 เส้น · เทปกาวย่น · ปลั๊กพ่วง

## 1.2 ประกอบส่วนกลไก 15 คัน

- [ ] ยึดมอเตอร์ ล้อ และลูกล้อหน้าเข้าแชสซีให้ครบทุกคัน

นักเรียนจะเป็นคนเดินสายเองในคาบ แต่ **งานขันน็อตครูทำมาก่อน** เพราะกินเวลา 25 นาทีต่อคันและสอน STEM ได้น้อย

## 1.3 บัดกรีตัวแบ่งแรงดัน 15 ชุด

- [ ] ต่อ 1 kΩ อนุกรมกับสาย ECHO แล้วแยก 2 kΩ ลง GND หุ้มด้วยท่อหด

HC-SR04 ส่งกลับมา 5 โวลต์ แต่ ESP32 รับได้ 3.3 โวลต์ ต่อตรงแล้วใช้ได้ในวันแรกแต่ขาจะเสื่อมจนพังในไม่กี่สัปดาห์ ดูวงจรใน [ผังการต่อสาย](docs/wiring.html)

## 1.4 ลงซอฟต์แวร์ทุกเครื่อง

- [ ] **Arduino IDE 2.x**
- [ ] **ESP32 board package** — ใส่ URL นี้ใน Preferences → Additional boards manager URLs แล้วค้น `esp32` ในตัวจัดการบอร์ด

  ```
  https://espressif.github.io/arduino-esp32/package_esp32_index.json
  ```

- [ ] **ไลบรารี** — ค้น `Adafruit SSD1306` ใน Library Manager กด **Install all** ระบบจะลง GFX และ BusIO ให้เอง
- [ ] **ไดรเวอร์ USB** — ดูชิปบนบอร์ดแล้วลงให้ตรง `CH340` หรือ `CP2102`
- [ ] **ตั้งค่าบอร์ด** Board = `ESP32 Dev Module` · Upload Speed = `921600` · Partition Scheme = ค่าเริ่มต้น อย่าเปลี่ยน

## 1.5 ประกอบรถต้นแบบ 1 คัน แล้วไล่ทดสอบทุกสเก็ตช์

**ขั้นตอนที่สำคัญที่สุดในทั้งหมด** อย่าข้าม

- [ ] ต่อสายครบตาม [ผังการต่อสาย](docs/wiring.html) แล้วอัปโหลด `01_HelloRover` — จอต้องติด ล้อซ้ายหมุนก่อน
- [ ] ไล่ `02` → `03` → `04` → `05` ให้ครบ
- [ ] **วัดค่า `MS_PER_CM` จริง** แล้วแก้ค่าเริ่มต้นใน `03_Tune` ให้ใกล้ของจริง เด็กจะได้ไม่เริ่มจากค่าที่ผิดมาก
- [ ] ถ้าจอไม่ติด ลองเปลี่ยนแอดเดรสจาก `0x3C` เป็น `0x3D` บางล็อตใช้คนละค่า
- [ ] ถ้า buzzer ไม่ดัง แปลว่าได้ passive มา ไม่ใช่ active ต้องเปลี่ยนโค้ดไปใช้ `tone()`

## ปุ่ม BOOT ใช้ยังไงในแต่ละสเก็ตช์

ใช้ปุ่มที่ติดมากับบอร์ด ไม่ต้องต่อปุ่มเพิ่ม

| สเก็ตช์ | กดสั้น | กดค้าง 1 วินาที |
|---|---|---|
| `01_HelloRover` | ไม่ใช้ วนทดสอบอัตโนมัติ | — |
| `02_Drive` | เริ่มภารกิจ | — |
| `03_Tune` | วิ่งตามโหมดที่เลือกอยู่ | เปลี่ยนโหมด |
| `04_Sense` | ขับเข้าหากำแพง | สลับเป็นโหมดอ่านค่าเฉย ๆ |
| `05_WebServer` | ปิด WiFi | เปิด WiFi |

## ช่วง 78–86 · เรื่องเดียวที่ต้องคุม

**ห้ามให้ทั้ง 15 ทีมเปิด WiFi พร้อมกัน** ย่าน 2.4 GHz มีช่องที่ไม่ทับกันจริงแค่ 3 ช่อง

เรียกทีละ 3–4 ทีมขึ้นมาเปิด ทดลอง แล้วสั่งปิดก่อนเรียกกลุ่มถัดไป โค้ดช่วยไว้ 3 ชั้นแล้วคือ WiFi ปิดอยู่ตอนเปิดเครื่อง ลดกำลังส่งเหลือ 8.5 dBm และปิดตัวเองใน 3 นาที แต่ยังต้องคุมคิวเอง

ทุกทีมใช้เลข `192.168.4.1` เหมือนกันหมด เพราะเป็นคนละเครือข่ายกัน จึงไม่ต้องมีตาราง IP และไม่ต้องมีเราเตอร์

## เฉลย `02_Drive_STUDENT`

**อย่าเพิ่งแจก** ปล่อยให้เด็กพลาดเองก่อน ห้าจุดแรกคือ

```cpp
void forward(int s)   { leftMotor( 1, s); rightMotor( 1, s); }
void backward(int s)  { leftMotor(-1, s); rightMotor(-1, s); }
void turnLeft(int s)  { leftMotor(-1, s); rightMotor( 1, s); }
void turnRight(int s) { leftMotor( 1, s); rightMotor(-1, s); }
void stopAll()        { leftMotor( 0, 0); rightMotor( 0, 0); }
```

จุดที่หกคือลำดับคำสั่งใน `mission()` ไม่มีคำตอบเดียวที่ถูก ดูตัวอย่างเต็มใน [`firmware/02_Drive_ANSWER`](firmware/02_Drive_ANSWER)

**สามอย่างที่เด็กมักพลาด** เจอแล้วอย่ารีบเฉลย ถามกลับว่า “ลองดูว่ารถหยุดตอนไหน”

- ลืม `stopAll()` หลัง `delay()` รถวิ่งต่อไม่หยุด
- ใส่ `turnLeft` แทน `turnRight` รถวนออกนอกเส้นทาง
- เขียน `leftMotor(1, s)` ทั้งสองบรรทัดใน `turnRight` รถวิ่งตรงแทนที่จะหมุน

# เมื่อมีปัญหาหน้างาน

กฎข้อเดียวเมื่อมี 15 ทีม — **ห้ามหยุดทั้งห้องเพื่อซ่อมทีมเดียว** สลับรถสำรองก่อน ค่อยหาสาเหตุตอนพัก

| อาการ | ทำทันที |
|---|---|
| เปิดสวิตช์แล้วไม่มีอะไรติดเลย | วัดไฟที่ขา 5V ของ L298N ถ้าไม่มีไฟคือ jumper 5V-EN หลุด |
| จอไม่ติดแต่บอร์ดติด | สลับสาย SDA กับ SCL ก่อนเป็นอันดับแรก |
| มอเตอร์หมุนมั่ว ไม่ตรงคำสั่ง | ตรวจว่าสาย GND ระหว่าง L298N กับ ESP32 ต่ออยู่จริง |
| บอร์ดรีเซ็ตวนตอนมอเตอร์หมุน | เปลี่ยนถ่านคู่ใหม่ |
| อัปโหลดค้างที่ Connecting | กดปุ่ม BOOT ค้างไว้ตอนขึ้น Connecting |
| ไม่เห็นพอร์ต COM | เปลี่ยนสาย USB ก่อนเป็นอันดับแรก |
| เซนเซอร์อ่านค่าติดลบตลอด | สลับสาย TRIG กับ ECHO |
| มือถือหาชื่อ ROVER ไม่เจอ | เดินเข้าใกล้รถอีก กำลังส่งถูกลดไว้ให้ไปได้ราว 5 เมตร |
| เชื่อม WiFi ได้แต่หน้าเว็บไม่ขึ้น | ปิดเน็ตมือถือชั่วคราว บางรุ่นวิ่งออกเน็ตแทน |

ตารางเต็มพร้อมประมาณเวลาที่เสียอยู่ใน [แผนดำเนินกิจกรรม](docs/index.html)
