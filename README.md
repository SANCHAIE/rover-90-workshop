## 00–08 · เปิดกล่อง

ให้เด็กจับของก่อน แล้วค่อยฟังทฤษฎี ไม่ใช่กลับกัน

ทีมเปิดกล่อง เช็กอุปกรณ์ตามใบงาน ตั้งชื่อทีมเขียนเทปกาวย่นแปะข้างรถ ครูอธิบายผังการต่อสายบนจอ 4 นาที เน้นสามข้อ — GND ต้องถึงกันหมด · ห้ามเปิดสวิตช์เอง · ผิดขั้วมอเตอร์ไม่พัง แต่ผิดขั้วไฟพัง

## 08–28 · เดินสาย

**ช่วงที่ยาวที่สุดและเป็นช่วงที่เด็กจะจำได้นานที่สุด** ปล่อยให้ต่อผิดได้ แต่ต้องไม่ให้จ่ายไฟตอนต่อผิด

ให้ต่อไล่ตามลำดับใน [ผังการต่อสาย](docs/wiring.html) คือ ไฟเลี้ยงก่อน แล้วมอเตอร์ แล้วเซนเซอร์ เหตุผลคือถ้าไฟเลี้ยงถูกตั้งแต่แรก ความเสียหายที่เหลือจะเป็นแค่ "ไม่ทำงาน" ไม่ใช่ "พัง"

> **กฎเหล็ก** ห้ามทีมใดเปิดสวิตช์ถ่านก่อนครูเซ็นชื่อในใบตรวจสาย
> นี่คือด่านเดียวที่กันไม่ให้ ESP32 พังกลางคาบ ผู้ช่วยยืนประจำโซนละ 5 ทีมเพื่อให้ตรวจทันภายใน 2 นาที

## 28–33 · อัปโหลดครั้งแรก

`01_HelloRover` คือโค้ดสั้นที่สุดที่พิสูจน์ว่าต่อถูก จอขึ้นชื่อทีม **ล้อซ้ายหมุนก่อน** แล้วล้อขวาหมุน

ประกาศเสียงดังว่าล้อซ้ายต้องหมุนก่อน ทีมที่ล้อขวาหมุนก่อนแปลว่าสลับสายควบคุม ให้แก้เดี๋ยวนี้ ถ้าค้างที่ `Connecting` ให้กดปุ่ม BOOT ค้างไว้

## 33–50 · เขียนโค้ดให้รถวิ่ง

`02_Drive_STUDENT` มีโครงฟังก์ชันเปล่ามาให้ นักเรียนเติมเนื้อในเอง แล้วเรียงลำดับคำสั่งเป็นภารกิจของตัวเอง

ให้เขียนคำตอบลงกระดาษในใบงานก่อนพิมพ์ลงคอม เพราะทีมละ 3 คนแต่มีคอมเครื่องเดียว วิธีนี้ทำให้คนที่ไม่ได้จับคีย์บอร์ดก็ยังต้องคิดด้วย

**สามอย่างที่เด็กมักพลาด** เจอแล้วอย่ารีบเฉลย ถามกลับว่า "ลองดูว่ารถหยุดตอนไหน"

- ลืม `stopAll()` หลัง `delay()` รถวิ่งต่อไม่หยุด
- ใส่ `turnLeft` แทน `turnRight` รถวนออกนอกเส้นทาง
- เขียน `leftMotor(1, s)` ทั้งสองบรรทัดใน `turnRight` รถวิ่งตรงแทนที่จะหมุน

<details>
<summary><b>เฉลย · กดเปิดเมื่อหมดเวลาแล้วเท่านั้น</b></summary>

```cpp
void forward(int s)   { leftMotor( 1, s); rightMotor( 1, s); }
void backward(int s)  { leftMotor(-1, s); rightMotor(-1, s); }
void turnLeft(int s)  { leftMotor(-1, s); rightMotor( 1, s); }
void turnRight(int s) { leftMotor( 1, s); rightMotor(-1, s); }
void stopAll()        { leftMotor( 0, 0); rightMotor( 0, 0); }
```

ลำดับคำสั่งใน `mission()` ไม่มีคำตอบเดียวที่ถูก ดูตัวอย่างเต็มใน [`firmware/02_Drive_ANSWER`](firmware/02_Drive_ANSWER)

</details>

## 53–68 · ปรับจูนจนแม่น

**หัวใจทาง STEM ของคาบนี้** รถวิ่งได้ไม่พอ ต้องวิ่งได้ตามที่สั่ง และนั่นต้องวัด

สั่งวิ่งตรง 2000 ms วัดระยะจริง คำนวณว่า 1 เซนติเมตรใช้เวลากี่มิลลิวินาที · รถเบี้ยวให้ปรับ `TRIM` ทีละ 0.05 · จบด้วยภารกิจวัดผล สั่งให้หยุดที่เส้น 100 ซม. ทีมละ 2 รอบ

> ทีมที่ไม่มีเครื่องมือวัดคือทีมที่นั่งดูเพื่อน ตรวจว่ามีตลับเมตรครบ 15 อันก่อนเริ่มช่วงนี้

## 68–78 · เซนเซอร์

แตะเรื่องเซนเซอร์พอให้เห็นว่าหุ่นยนต์ตัดสินใจเองได้ ไม่ลงลึกเรื่องระบบควบคุม

อ่านค่าอัลตราโซนิกขึ้นจอบนรถ เอามือโบกดูค่าวิ่ง เทียบไม้บรรทัด แล้วเขียนเงื่อนไขเดียวคือ ใกล้กว่า 15 ซม. ให้หยุดและ buzzer ร้อง

ถ้าช่วงเดินสายเกินเวลา ตัดการเทียบไม้บรรทัดออก เหลือแค่เขียนเงื่อนไขหยุดก่อนชน ใช้เวลา 4 นาที

## 78–86 · รถปล่อย WiFi เอง

ไม่ต้องมีเราเตอร์ ไม่ต้องมีอินเทอร์เน็ต ทุกทีมใช้เลข `192.168.4.1` เหมือนกันหมดเพราะเป็นคนละเครือข่ายกัน จึงไม่ต้องมีตาราง IP

```
กดปุ่ม BOOT ค้าง 1 วินาที  →  รถปล่อย WiFi ชื่อ ROVER-01
มือถือเชื่อม รหัสผ่าน rover2026
เปิดเบราว์เซอร์ไปที่ 192.168.4.1
กดปุ่ม BOOT สั้น ๆ         →  ปิด WiFi คืนคลื่นให้ทีมถัดไป
```

> **เรื่องเดียวที่ต้องคุมในช่วงนี้** ห้ามให้ทั้ง 15 ทีมเปิด WiFi พร้อมกัน ย่าน 2.4 GHz มีช่องที่ไม่ทับกันจริงแค่ 3 ช่อง
> เรียกทีละ 3–4 ทีมขึ้นมาเปิด ทดลอง แล้วสั่งปิดก่อนเรียกกลุ่มถัดไป
> โค้ดช่วยไว้ 3 ชั้นแล้ว คือ WiFi ปิดอยู่ตอนเปิดเครื่อง ลดกำลังส่งเหลือ 8.5 dBm และปิดตัวเองใน 3 นาที แต่คิวยังต้องคุมเอง

ถ้าเน็ตในห้องมีปัญหาหรือเวลาไม่พอ **ข้ามช่วงนี้ทั้งช่วงได้** ส่วนอื่นของคาบไม่กระทบเลย

## 86–90 · สรุป

ถามแล้วให้เด็กตอบเอง อย่าเฉลย

- รถทุกคันใช้ของชุดเดียวกันและโค้ดเดียวกัน ทำไมค่าที่จูนได้ไม่เท่ากัน
- ถ้าถ่านอ่อนลง ค่าที่จูนไว้วันนี้จะยังใช้ได้ไหม ต้องเพิ่มอะไรถึงจะไม่ต้องจูนใหม่
- ทุกทีมใช้เลข 192.168.4.1 เหมือนกัน ทำไมไม่ชนกัน

# เมื่อมีปัญหาหน้างาน

กฎข้อเดียวเมื่อมี 15 ทีม **ห้ามหยุดทั้งห้องเพื่อซ่อมทีมเดียว** สลับรถสำรองก่อน ค่อยหาสาเหตุตอนพัก

| อาการ | ทำทันที |
|---|---|
| เปิดสวิตช์แล้วไม่มีอะไรติดเลย | วัดไฟที่ขา 5V ของ L298N ถ้าไม่มีไฟคือ jumper 5V-EN หลุด |
| จอไม่ติดแต่บอร์ดติด | สลับสาย SDA กับ SCL ก่อนเป็นอันดับแรก |
| มอเตอร์หมุนมั่ว ไม่ตรงคำสั่ง | ตรวจว่าสาย GND ระหว่าง L298N กับ ESP32 ต่ออยู่จริง |
| บอร์ดรีเซ็ตวนตอนมอเตอร์หมุน | เปลี่ยนถ่านคู่ใหม่ |
| อัปโหลดค้างที่ Connecting | กดปุ่ม BOOT ค้างไว้ตอนขึ้น Connecting |
| ไม่เห็นพอร์ต COM | เปลี่ยนสาย USB ก่อนเป็นอันดับแรก |
| รถวิ่งเบี้ยวมาก | ปรับ TRIM ทีละ 0.05 อย่าปรับทีเดียวเยอะ |
| เซนเซอร์อ่านค่าติดลบตลอด | สลับสาย TRIG กับ ECHO |
| ทีมต่อสายผิดจนโมดูลไหม้ | สลับรถสำรองทันที เก็บคันเสียไว้ซ่อมทีหลัง |
| มือถือหาชื่อ ROVER ไม่เจอ | เดินเข้าใกล้รถอีก กำลังส่งถูกลดไว้ให้ไปได้ราว 5 เมตร |
| เชื่อม WiFi ได้แต่หน้าเว็บไม่ขึ้น | ปิดเน็ตมือถือชั่วคราว บางรุ่นวิ่งออกเน็ตแทน |

ตารางเต็มพร้อมประมาณเวลาที่เสียอยู่ใน [แผนรายนาที](docs/index.html)
