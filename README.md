# Rover 90 — เวิร์กช็อปหุ่นยนต์ ESP32 สำหรับนักเรียน ม.ปลาย

ชุดกิจกรรม **90 นาที** ที่พานักเรียนจากกล่องอุปกรณ์เปล่า ไปถึงรถที่ต่อวงจรเอง เขียนโค้ดเอง ปรับจูนจนวิ่งแม่น และเปิดหน้าเว็บของตัวเองบนมือถือได้

ออกแบบสำหรับ **15 ทีม ทีมละ 2–3 คน** ครู 1 คนกับผู้ช่วย 2–3 คน

---

## จุดเน้นของกิจกรรม

| ช่วง | เวลา | นักเรียนได้ทำอะไร |
|---|---|---|
| เดินสายทั้งคัน | 20 นาที | ต่อไฟเลี้ยง มอเตอร์ เซนเซอร์ และจอ ด้วยมือตัวเอง |
| เขียนโค้ดให้รถวิ่ง | 17 นาที | เติมฟังก์ชันเอง แล้วเรียงลำดับคำสั่งเป็นภารกิจ |
| ปรับจูนความแม่น | 15 นาที | วัดจริง คำนวณ ms ต่อ ซม. แก้อาการรถเบี้ยว |
| เซนเซอร์ | 10 นาที | อัลตราโซนิกขึ้นจอ เขียนเงื่อนไขให้รถหยุดเอง |
| IoT | 8 นาที | รถปล่อย WiFi ของตัวเองและเสิร์ฟหน้าเว็บ |

**แผนดำเนินกิจกรรมฉบับเต็ม** อยู่ที่ [`docs/runsheet.html`](docs/runsheet.html) — เปิดในเบราว์เซอร์ มีไทม์ไลน์รายนาที ใบตรวจสาย เช็กลิสต์เตรียมงาน และตารางแก้ปัญหาหน้างาน

## ผังการต่อสาย

| อุปกรณ์ | ขา ESP32 |
|---|---|
| L298N `ENA` / `IN1` / `IN2` | `14` / `27` / `26` |
| L298N `IN3` / `IN4` / `ENB` | `25` / `33` / `32` |
| HC-SR04 `TRIG` / `ECHO` | `5` / `18` |
| OLED `SDA` / `SCL` | `21` / `22` |
| Buzzer | `4` |
| ปุ่ม BOOT (มีบนบอร์ดแล้ว) | `0` |

**ขา ECHO ต้องผ่านตัวแบ่งแรงดันเสมอ** HC-SR04 ส่งออกมา 5V แต่ ESP32 รับได้ 3.3V

```
ECHO ──[ 1 kΩ ]──┬──────► GPIO 18
                 │
              [ 2 kΩ ]
                 │
                GND
```

ต่อตรงแล้วใช้ได้ในวันแรก แต่ขาจะเสื่อมไปเรื่อย ๆ ถ้าชุดนี้ใช้ซ้ำหลายรุ่น ควรบัดกรีติดไว้ล่วงหน้า

## ติดตั้งเครื่องมือ

**1. Arduino IDE 2.x**

**2. ESP32 board package** — ใส่ URL นี้ใน Preferences → Additional boards manager URLs

```
https://espressif.github.io/arduino-esp32/package_esp32_index.json
```

**3. ไลบรารี** — ค้น `Adafruit SSD1306` ใน Library Manager แล้วกด **Install all** ระบบจะลง `Adafruit GFX` และ `Adafruit BusIO` ให้เอง

**4. ตั้งค่าบอร์ด**

| หัวข้อ | ค่า |
|---|---|
| Board | ESP32 Dev Module |
| Upload Speed | 921600 |
| Partition Scheme | Default 4MB with spiffs (อย่าเปลี่ยน) |

> สเก็ตช์ตระกูล `05` ใช้พื้นที่ 75–81% ของพาร์ทิชันเริ่มต้น ถ้าเลือกพาร์ทิชันที่เล็กกว่านี้จะอัปโหลดไม่ผ่าน

**5. ไดรเวอร์ USB** — ดูชิปบนบอร์ดแล้วลงให้ตรง `CH340` หรือ `CP2102`

## ส่วน IoT ทำงานอย่างไร

`05_WebServer` ทำให้รถแต่ละคัน **ปล่อย WiFi ของตัวเองและเสิร์ฟหน้าเว็บในตัว** ไม่ต้องมีเราเตอร์ ไม่ต้องมีอินเทอร์เน็ต ไม่ต้องตั้งค่าอะไรล่วงหน้า สิ่งที่ต้องแก้ในโค้ดมีบรรทัดเดียวคือ `TEAM_NO`

```
กดปุ่ม BOOT ค้าง 1 วินาที  →  รถปล่อย WiFi ชื่อ ROVER-01
มือถือเชื่อม รหัสผ่าน rover2026
เปิดเบราว์เซอร์ไปที่ 192.168.4.1
กดปุ่ม BOOT สั้น ๆ         →  ปิด WiFi คืนคลื่นให้ทีมถัดไป
```

ทุกทีมใช้เลข `192.168.4.1` เหมือนกันหมด เพราะเป็นคนละเครือข่ายกัน จึงไม่ต้องมีตาราง IP

**ห้ามให้ทั้ง 15 ทีมเปิด WiFi พร้อมกัน** ย่าน 2.4 GHz มีช่องที่ไม่ทับกันจริงแค่ 3 ช่อง โค้ดจึงมีสามชั้นป้องกันไว้

- WiFi ปิดอยู่ตอนเปิดเครื่อง ต้องกดปุ่มเองถึงจะเปิด
- ลดกำลังส่งเหลือ 8.5 dBm สัญญาณไปได้ราว 5 เมตร ไม่ข้ามไปกวนโต๊ะอื่น
- ปิดตัวเองอัตโนมัติใน 3 นาที มีนับถอยหลังบนจอ

ครูเรียกทีละ 3–4 ทีมขึ้นมาเปิด ทดลอง แล้วปิดก่อนเรียกกลุ่มถัดไป

## หมายเหตุ

**ข้อความบนจอ OLED เป็นภาษาอังกฤษ** เพราะ SSD1306 ไม่มีฟอนต์ไทยในตัว ส่วนคอมเมนต์ในโค้ดและข้อความใน Serial Monitor เป็นภาษาไทยทั้งหมด

**เอกสารสำหรับปริ๊นต์** อยู่ใน `handouts/` เป็นไฟล์ Word แก้ได้ ใช้ฟอนต์ TH SarabunPSK
ใบตรวจสายพอดี 1 หน้า A4 แจกทีมละแผ่น ส่วนใบงาน 6 หน้า แนะนำให้ปริ๊นต์สองหน้าต่อแผ่น
