# Rover 90

**สร้างรถหุ่นยนต์ ESP32 ของคุณเอง — ต่อวงจรเอง เขียนโค้ดเอง จูนจนแม่น แล้วเปิดหน้าเว็บของรถบนมือถือ**

ทำตามทีละขั้นจากบนลงล่าง ใช้เวลาราว 90 นาที ไม่ต้องมีพื้นฐานอิเล็กทรอนิกส์มาก่อน

---

## ต้องมีอะไรบ้าง

**อุปกรณ์** — ESP32 NodeMCU 30 pin พร้อมฐาน · แชสซีรถ 2WD ประกอบล้อแล้ว · L298N · HC-SR04 · จอ OLED 0.96" · buzzer · ถ่าน 18650 ×2 พร้อมกล่อง · สายจัมเปอร์ · ตัวต้านทาน 1kΩ + 2kΩ · breadboard เล็ก
รายการเต็มอยู่ใน [`bom/BOM.xlsx`](bom/BOM.xlsx)

**เครื่องมือ** — คอมที่ลง Arduino IDE แล้ว (วิธีลงอยู่ท้ายหน้า) · ตลับเมตรหรือไม้บรรทัด · มือถือ

# ขั้นที่ 1 · ต่อวงจร

เปิด **[ผังการต่อสาย](docs/wiring.html)** คู่กันไปเลย มีรูปครบทุกเส้น

ต่อทีละกลุ่ม **ตามลำดับนี้เท่านั้น** เพราะกลุ่มแรกคือกลุ่มเดียวที่ต่อผิดแล้วของพัง กลุ่มหลังต่อผิดแค่ทำงานเพี้ยน แก้ทีหลังได้

1. **ไฟเลี้ยง 4 เส้น** — ถ่านเข้า L298N แล้ว L298N แบ่งไฟ 5V ไปเลี้ยง ESP32 · สายแดงเข้า `12V` สายดำเข้า `GND` ตรวจสีก่อนขันทุกครั้ง · jumper `5V-EN` ต้องคาไว้
2. **มอเตอร์ 10 เส้น** — มอเตอร์เข้าขั้วสกรู สายควบคุม 6 เส้นเข้าขา `14 27 26 25 33 32` · ถอด jumper ครอบ `ENA` `ENB` ออกก่อน
3. **เซนเซอร์ 10 เส้น** — HC-SR04 ใช้ไฟ `5V` แต่จอ OLED ใช้ `3V3` **ห้ามสลับ จอไหม้** · ขา ECHO ต้องผ่านตัวแบ่งแรงดัน 1kΩ+2kΩ เสมอ

**ก่อนเปิดสวิตช์ ตรวจ 4 จุดนี้ซ้ำ**

- [ ] ขั้วถ่านเข้า L298N ถูกด้าน — ผิดคือไหม้ทันที
- [ ] มีสาย GND เชื่อม L298N กับ ESP32 — ขาดแล้วมอเตอร์ทำงานมั่ว หาสาเหตุยากที่สุด
- [ ] ECHO ผ่านตัวแบ่งแรงดันแล้ว
- [ ] จอ OLED เสียบที่ 3V3 ไม่ใช่ 5V

ทำในเวิร์กช็อป ให้ผู้ดูแลตรวจและเซ็น[ใบตรวจสาย](handouts)ก่อน แล้วค่อยเปิดสวิตช์

# ขั้นที่ 2 · ปลุกรถให้ตื่น

เปิด [`firmware/01_HelloRover`](firmware/01_HelloRover) แก้บรรทัด `TEAM_NAME` เป็นชื่อทีมคุณ **ยกล้อให้ลอยจากพื้น** แล้วกด Upload

**ต้องเห็นตามนี้เป๊ะ ๆ** — จอขึ้นชื่อทีม → **ล้อซ้ายหมุนก่อน** 1 วินาที → ล้อขวาหมุนตาม → buzzer ร้อง 2 ครั้ง แล้ววนใหม่

| เห็นแบบนี้แทน | แปลว่า | แก้โดย |
|---|---|---|
| อัปโหลดค้างที่ `Connecting` | บอร์ดไม่เข้าโหมดแฟลช | กดปุ่ม BOOT ค้างไว้จนขึ้น % |
| ไม่เห็นพอร์ต COM | สาย USB เป็นสายชาร์จ | เปลี่ยนสายก่อนเป็นอันดับแรก |
| จอไม่ติด ไฟบนบอร์ดกะพริบถี่ | SDA/SCL สลับกัน | สลับสองเส้นนั้น |
| ล้อขวาหมุนก่อนล้อซ้าย | สายควบคุมสลับฝั่ง | สลับชุด 14/27/26 กับ 25/33/32 |
| ล้อหมุนถอยหลัง | สายมอเตอร์กลับขั้ว | สลับสาย 2 เส้นของข้างนั้น ไม่พัง |

ผ่านขั้นนี้ = วงจรถูกทุกเส้น ที่เหลือเป็นเรื่องโค้ดล้วน ๆ แล้ว

# ขั้นที่ 4 · จูนจนแม่น

รถวิ่งได้ไม่พอ ต้องวิ่งได้ **ตามระยะที่สั่ง** — และนั่นต้องวัด ไม่ใช่เดา

อัปโหลด [`firmware/03_Tune`](firmware/03_Tune) · กดปุ่ม BOOT **ค้าง 1 วินาที** เพื่อเปลี่ยนโหมด · กด **สั้น** เพื่อวิ่ง

1. โหมด `TEST 2s` — รถวิ่งตรง 2 วินาที วัดระยะที่ได้จริงด้วยตลับเมตร ทำ 3 รอบ เอาค่าเฉลี่ย
2. คำนวณ `MS_PER_CM = 2000 ÷ ระยะเฉลี่ย(ซม.)` แล้วแก้ค่านี้ในโค้ด อัปโหลดใหม่
3. โหมด `GO 50cm` — ทดสอบ ถ้าคลาดมากกลับไปแก้ค่า
4. รถวิ่งเบี้ยว? ลด `TRIM_L` หรือ `TRIM_R` ของฝั่งที่แรงกว่า **ทีละ 0.05**
5. โหมด `GO 100cm` — ภารกิจจริง วัดว่าพลาดจากเส้น 100 ซม. กี่เซนติเมตร

ได้ต่ำกว่า 5 ซม. ถือว่าเก่งมากแล้วสำหรับรถที่ไม่มีเซนเซอร์วัดล้อ
ลองเปลี่ยนถ่านเป็นคู่ที่อ่อนกว่าแล้ววิ่งซ้ำดู — ค่าที่จูนไว้จะเพี้ยนทันที นั่นแหละคือเหตุผลที่หุ่นยนต์จริงต้องมีเซนเซอร์

# ขั้นที่ 6 · เปิดเว็บของรถ

อัปโหลด [`firmware/05_WebServer`](firmware/05_WebServer) แก้ `TEAM_NO` เป็นเลขทีมคุณ

```
กดปุ่ม BOOT ค้าง 1 วินาที   →  รถปล่อย WiFi ชื่อ ROVER-01
มือถือเชื่อม WiFi นั้น        รหัส rover2026
เปิดเบราว์เซอร์ พิมพ์         192.168.4.1
```

คุณจะเห็นหน้าเว็บที่รถเสิร์ฟเองจากในตัว — ตัวเลขระยะวิ่งสด กราฟย้อนหลัง ค่าที่คุณจูนไว้ และปุ่มบังคับรถ ทั้งหมดนี้**ไม่ได้ใช้อินเทอร์เน็ตเลย** รถคือทั้งเสาสัญญาณและเว็บเซิร์ฟเวอร์ในตัวเดียว

เสร็จแล้วกดปุ่ม BOOT สั้น ๆ ปิด WiFi คืนคลื่นให้ทีมข้าง ๆ (ถ้าเปิดพร้อมกันทั้งห้อง คลื่นจะแน่นจนเชื่อมไม่ติดสักทีม — ในเวิร์กช็อปจึงผลัดกันเปิดทีละ 3–4 ทีม)

มือถือหาชื่อ ROVER ไม่เจอ ให้เดินเข้าใกล้รถ สัญญาณถูกลดกำลังไว้ราว 5 เมตร · เชื่อมได้แต่หน้าเว็บไม่ขึ้น ให้ปิดเน็ตมือถือชั่วคราว

**จบแล้ว!** คำถามทิ้งท้าย — ทุกทีมใช้เลข 192.168.4.1 เหมือนกันหมด ทำไมถึงไม่ชนกัน?

# ต่อยอดที่บ้าน

ในชุดมีของที่ยังไม่ได้ใช้อีก 3 ชิ้น รอคุณอยู่

- **โมดูล IR 3 ตา** — ติดคว่ำหน้ารถเป็นเซนเซอร์กันตกขอบโต๊ะ หรือหันหน้าเป็นรถวิ่งตามฝ่ามือ
- **เซอร์โว SG90** — ติด HC-SR04 บนหัวหมุน กวาด 180° ทำเรดาร์สแกนห้อง
- **Encoder LM393 ×2** — วัดรอบล้อจริง จะได้เลิกจูนใหม่ทุกครั้งที่เปลี่ยนถ่าน (คำตอบของขั้นที่ 4 นั่นเอง)

โค้ดตัวเลือกส่งข้อมูลขึ้น Google Sheet อยู่ใน [`optional/`](optional/google-sheet-iot/)

# ติดตั้ง Arduino IDE ครั้งแรก

1. ลง **Arduino IDE 2.x** จาก arduino.cc
2. Preferences → Additional boards manager URLs วางบรรทัดนี้ แล้วไปที่ Boards Manager ค้น `esp32` กดติดตั้ง

   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```

3. Library Manager ค้น `Adafruit SSD1306` กด **Install all**
4. ลงไดรเวอร์ USB ตามชิปบนบอร์ด — `CH340` หรือ `CP2102`
5. เลือก Board = `ESP32 Dev Module` · Upload Speed = `921600` · Partition Scheme ค่าเริ่มต้น
