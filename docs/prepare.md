# ก่อนถึงวันงาน

งานเตรียมทั้งหมด แยกออกมาจาก [README](../README.md) เพราะคนละคนกันอาจทำคนละส่วน
**เวลาเตรียมรวมราว 7 ชั่วโมง ต่อเวลาสอน 90 นาที** วางแผนล่วงหน้าอย่างน้อย 1 สัปดาห์

## สัปดาห์ก่อนงาน

### ซื้อของส่วนกลาง

อุปกรณ์ในชุดนักเรียนมีครบแล้ว ของส่วนกลางยังต้องหาเอง รายการเต็มอยู่ในชีตที่สองของ [`bom/BOM.xlsx`](../bom/BOM.xlsx)

สองรายการนี้ถ้าไม่มี กิจกรรมเดินไม่ได้จริง ๆ

- [ ] **เครื่องชาร์จ 18650 แบบ 4 ช่อง 2 เครื่อง** ถ่าน 30 ก้อนมาแบบไม่ได้ชาร์จ
- [ ] **ตลับเมตรหรือไม้บรรทัดเหล็ก ทีมละ 1 อัน** ช่วงปรับจูนคือการวัดล้วน ๆ

ที่เหลือควรมี

- [ ] ถ่าน 18650 สำรอง 4 คู่ · มัลติมิเตอร์ 2 เครื่อง · สายต่อ USB 5 เส้น · เทปกาวย่น · ปลั๊กพ่วง

### ประกอบส่วนกลไก 15 คัน

- [ ] ยึดมอเตอร์ ล้อ และลูกล้อหน้าเข้าแชสซีให้ครบทุกคัน

นักเรียนเป็นคนเดินสายเองในคาบ แต่งานขันน็อตครูทำมาก่อน เพราะกินเวลา 25 นาทีต่อคันและสอน STEM ได้น้อย

### บัดกรีตัวแบ่งแรงดัน 15 ชุด

- [ ] ต่อ 1 kΩ อนุกรมกับสาย ECHO แล้วแยก 2 kΩ ลง GND หุ้มด้วยท่อหด

HC-SR04 ส่งกลับมา 5 โวลต์ แต่ ESP32 รับได้ 3.3 โวลต์ ต่อตรงแล้วใช้ได้ในวันแรกแต่ขาจะเสื่อมจนพังในไม่กี่สัปดาห์ ดูวงจรใน [ผังการต่อสาย](wiring.html)

### ลงซอฟต์แวร์ทุกเครื่อง

- [ ] **Arduino IDE 2.x**
- [ ] **ESP32 board package** ใส่ URL นี้ใน Preferences → Additional boards manager URLs แล้วค้น `esp32` ในตัวจัดการบอร์ด

  ```
  https://espressif.github.io/arduino-esp32/package_esp32_index.json
  ```

- [ ] **ไลบรารี** ค้น `Adafruit SSD1306` ใน Library Manager กด **Install all** ระบบจะลง GFX และ BusIO ให้เอง
- [ ] **ไดรเวอร์ USB** ดูชิปบนบอร์ดแล้วลงให้ตรง `CH340` หรือ `CP2102`
- [ ] **ตั้งค่าบอร์ด** Board = `ESP32 Dev Module` · Upload Speed = `921600` · Partition Scheme = ค่าเริ่มต้น อย่าเปลี่ยน

### ประกอบรถต้นแบบ 1 คัน แล้วไล่ทดสอบทุกสเก็ตช์

**ขั้นตอนที่สำคัญที่สุดในทั้งหมด อย่าข้าม** โค้ดคอมไพล์ผ่านไม่ได้แปลว่าใช้กับของที่ซื้อมาได้

- [ ] ต่อสายครบตาม [ผังการต่อสาย](wiring.html) แล้วอัปโหลด `01_HelloRover` จอต้องติด ล้อซ้ายหมุนก่อน
- [ ] ไล่ `02` → `03` → `04` → `05` ให้ครบ
- [ ] **วัดค่า `MS_PER_CM` จริง** แล้วแก้ค่าเริ่มต้นใน `03_Tune` ให้ใกล้ของจริง เด็กจะได้ไม่เริ่มจากค่าที่ผิดมาก
- [ ] ถ้าจอไม่ติด ลองเปลี่ยนแอดเดรสจาก `0x3C` เป็น `0x3D` บางล็อตใช้คนละค่า
- [ ] ถ้า buzzer ไม่ดัง แปลว่าได้ passive มา ไม่ใช่ active ต้องเปลี่ยนไปใช้ `tone()`

## วันก่อนงาน

- [ ] ชาร์จถ่าน 18650 ให้เต็มทั้ง 30 ก้อน **และวัดแรงดันทุกก้อน** ก้อนไหนต่ำผิดปกติคัดออก
- [ ] แก้ `TEAM_NAME` หรือ `TEAM_NO` แล้วแฟลช `01_HelloRover` ลงบอร์ดทีละตัวจนครบ 15 ราวบอร์ดละ 40 วินาที
- [ ] ติดสติกเกอร์หมายเลขทีมบนตัวบอร์ด
- [ ] ปริ๊นต์ [ใบตรวจสาย](../handouts) ทีมละแผ่น และ [ใบงานนักเรียน](../handouts) 6 หน้า แนะนำสองหน้าต่อแผ่น
- [ ] ปริ๊นต์ [ผังการต่อสาย](wiring.html) ขยายใหญ่แปะหน้าห้อง
- [ ] ถ่ายรูปรถต้นแบบ 6 รูปตาม [รายการนี้](image-prompts.md)
- [ ] **นัดผู้ช่วย 2–3 คน** แบ่งโซนละ 5 ทีม บรีฟเรื่องเดียวที่สำคัญที่สุดคือ ห้ามให้ทีมไหนเปิดสวิตช์ก่อนตรวจสายและเซ็นชื่อ
