# ติดตั้งกราฟรวมของห้อง (Google Sheet + Apps Script)

ทำครั้งเดียว ใช้ได้ทุกปี ใช้เวลาราว 15 นาที
**ต้องทำและทดสอบให้เสร็จก่อนวันงานอย่างน้อย 1 วัน**

---

## ขั้นที่ 1 · สร้างชีต

1. เปิด [sheets.new](https://sheets.new) สร้างสเปรดชีตใหม่
2. ตั้งชื่อไฟล์ว่า `Rover Workshop 2569`
3. ยังไม่ต้องทำอะไรกับตัวชีต สคริปต์จะสร้างแท็บ `data` และหัวตารางให้เอง

---

## ขั้นที่ 2 · วางสคริปต์

1. เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดตัวอย่างที่มีอยู่ออกให้หมด
3. เปิดไฟล์ `Code.gs` ที่แนบมา คัดลอกทั้งไฟล์มาวาง
4. กด **บันทึก** (ไอคอนแผ่นดิสก์)

---

## ขั้นที่ 3 · อนุญาตให้สคริปต์เขียนชีต

ขั้นนี้ข้ามไม่ได้ ถ้าไม่ทำ ตอน ESP32 ยิงข้อมูลมาจะเงียบไปเฉย ๆ

1. ที่แถบบนสุด เลือกฟังก์ชัน **`testAddRow`** แล้วกด **เรียกใช้ (Run)**
2. จะขึ้นหน้าต่างขอสิทธิ์ → **ตรวจสอบสิทธิ์ (Review permissions)**
3. เลือกบัญชี Google ของตัวเอง
4. หน้าจอจะเตือนว่า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง (Advanced)** → **ไปที่ ... (unsafe)**

   > ไม่ต้องกังวลครับ ข้อความนี้ขึ้นกับทุกสคริปต์ที่เขียนเอง เพราะยังไม่ได้ส่งให้ Google ตรวจ ไม่ได้แปลว่าโค้ดอันตราย โค้ดชุดนี้เขียนลงชีตของคุณเองอย่างเดียว
5. กด **อนุญาต (Allow)**
6. กลับไปดูที่สเปรดชีต ต้องมีแท็บ `data` โผล่มา พร้อมข้อมูลของ "ทีม 99" หนึ่งแถว

**ถ้าถึงตรงนี้แล้วมีแถวทีม 99 ขึ้นมา แปลว่าครึ่งแรกสำเร็จแล้ว**

---

## ขั้นที่ 4 · Deploy ให้ ESP32 ยิงเข้ามาได้

1. มุมขวาบน กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้ใหม่ (New deployment)**
2. กดไอคอนเฟือง เลือกประเภท **เว็บแอป (Web app)**
3. ตั้งค่าสองบรรทัดนี้ **ให้ตรงเป๊ะ** ไม่งั้นจะใช้ไม่ได้

   | ช่อง | ต้องเลือก |
   |---|---|
   | ดำเนินการในชื่อ (Execute as) | **ฉัน (Me)** |
   | ผู้ที่มีสิทธิ์เข้าถึง (Who has access) | **ทุกคน (Anyone)** |

   > ต้องเป็น **Anyone** เท่านั้น เพราะ ESP32 ไม่มีบัญชี Google ให้ล็อกอิน
   > ลิงก์ที่ได้จะยาวและเดาไม่ได้ คนอื่นจะเจอก็ต่อเมื่อมีลิงก์นี้เท่านั้น

4. กด **ทำให้ใช้งานได้ (Deploy)**
5. คัดลอก **URL ของเว็บแอป** ที่ได้ หน้าตาแบบนี้

   ```
   https://script.google.com/macros/s/AKfycbx.....................3Qw/exec
   ```

---

## ขั้นที่ 5 · ใส่ลิงก์ลงในโค้ด ESP32

เปิดไฟล์ `05_SendToSheet.ino` แก้สามบรรทัดบนสุด

```cpp
const char* WIFI_SSID = "RoverClass";        // ชื่อฮอตสปอตมือถือครู
const char* WIFI_PASS = "rover2026";         // รหัสผ่าน
const char* SCRIPT_URL =
  "https://script.google.com/macros/s/AKfycbx......../exec";   // วางลิงก์จากขั้นที่ 4
```

จากนั้น **แก้ `TEAM_NO` ให้ตรงกับหมายเลขทีม** แล้วอัปโหลดลงบอร์ดของทีมนั้น

---

## ขั้นที่ 6 · ทดสอบจริงก่อนวันงาน

1. เปิดฮอตสปอตด้วยมือถือเครื่องที่จะใช้จริง ตั้งชื่อและรหัสตามที่ใส่ในโค้ด
2. เปิดสวิตช์ ESP32 กดปุ่ม BOOT
3. จอต้องขึ้นตามลำดับ `STEP 1 WiFi` → `STEP 2 sending` → `SUCCESS sent!`
4. กลับไปดูชีต ต้องมีแถวใหม่ขึ้นมาภายใน 2-3 วินาที

**ทดสอบด้วย ESP32 อย่างน้อย 2 ตัวพร้อมกัน** เพื่อยืนยันว่าล็อกกันข้อมูลทับได้จริง

---

## ขั้นที่ 7 · สร้างกราฟสำหรับฉายขึ้นจอ

1. ที่แท็บ `data` เลือกคอลัมน์ **B** (ทีม) แล้วกด Ctrl ค้างเลือกคอลัมน์ **H** (คลาดเคลื่อนเฉลี่ย)
2. เมนู **แทรก (Insert) → แผนภูมิ (Chart)**
3. เลือกชนิด **แผนภูมิคอลัมน์ (Column chart)**
4. ในแถบตั้งค่าด้านขวา แก้ช่วงข้อมูลให้เป็น `data!B:B` และ `data!H:H`

   > สำคัญ: ต้องใช้ทั้งคอลัมน์แบบ `B:B` ไม่ใช่ `B2:B16` กราฟถึงจะโตตามข้อมูลที่ทยอยเข้ามาเอง

5. ตั้งชื่อกราฟว่า **ความคลาดเคลื่อนของแต่ละทีม (ซม.)**
6. ย้ายกราฟไปวางในแท็บใหม่ชื่อ `กราฟ` แล้วกด **ดู → เต็มหน้าจอ** ตอนฉาย

กราฟจะอัปเดตเองทันทีที่มีทีมส่งข้อมูลเข้ามา ไม่ต้องกดรีเฟรช

---

## ก่อนเริ่มคาบทุกครั้ง

เปิด Apps Script เลือกฟังก์ชัน **`clearBeforeClass`** แล้วกด Run
ข้อมูลเก่าจะถูกล้าง หัวตารางและกราฟยังอยู่เหมือนเดิม

---

## แก้ปัญหา

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| จอค้างที่ `STEP 1 WiFi` | ฮอตสปอตปิด หรือชื่อ/รหัสไม่ตรง | ถ้าใช้ iPhone ต้องเปิดหน้า Personal Hotspot ค้างไว้ อย่ากดออก |
| ขึ้น `FAILED no reply` | ยังไม่ได้ Deploy หรือลิงก์ผิด | ตรวจว่าลิงก์ลงท้ายด้วย `/exec` ไม่ใช่ `/dev` |
| ส่งได้แต่ชีตว่าง | ยังไม่ได้กด Authorize ในขั้นที่ 3 | กลับไปทำขั้นที่ 3 ให้ครบ |
| ได้ข้อความ `BUSY` | ส่งพร้อมกันหลายเครื่องเกินไป | กด BOOT ส่งซ้ำอีกครั้ง |
| แก้โค้ดแล้วไม่มีผล | Deploy เดิมยังชี้เวอร์ชันเก่า | Deploy → จัดการ → แก้ไข → เวอร์ชัน: ใหม่ → Deploy |

---

## หมายเหตุเรื่องความเป็นส่วนตัว

เว็บแอปที่ตั้งค่าเป็น Anyone หมายถึง **ใครที่มีลิงก์นี้จะเพิ่มแถวลงชีตได้** แต่จะอ่านหรือแก้ข้อมูลในชีตไม่ได้เลย เพราะสคริปต์ไม่ได้ส่งข้อมูลกลับออกไป

ลิงก์นี้ควรอยู่ในโค้ดของโรงเรียนเท่านั้น ไม่ควรโพสต์สาธารณะ ถ้าหลุดออกไปและมีคนยิงข้อมูลขยะเข้ามา ให้ Deploy → จัดการ → เก็บถาวร แล้ว Deploy ใหม่เพื่อเปลี่ยนลิงก์
